# 図表の掲載範囲と許可

2026年11月23日、ユーザーからPR #8に固定8画像の比較図を掲載する明示的な許可を得た。許可対象は本ディレクトリの複合PNG16枚（深度図8枚、絶対誤差図8枚）であり、各図にRGBおよびGTの表示が含まれる。

生成時のprovenance.jsonには、生成時点の意図として rgb_gt_and_depth_maps_private=true が記録されている。この記録は生成時の状態を表す。生成後の許可に基づき、PR #8では複合図のみを公開する。元のRGB/GTファイル、checkpoint、大容量prediction cacheは掲載していない。

最終版はコンタクトシートで全16枚を再確認し、Validation 007の2枚を元解像度でも確認した。
