# 2026-11-14 final result highlights

This directory contains compact report tables and dependency-free SVG figures for the fixed epoch-5 Validation128 evaluation. Values in the compact result CSVs are rounded for review; the GPGPU4 NFS archive contains the full precision evaluation output, per-image results, bootstrap tables, condition summaries, logs, run signatures, receipts, and checkpoints. RGB/GT source images and prediction caches are excluded.

- summary_metrics.csv: all 9 training/inference combinations.
- primary_comparisons.csv: P2 paired comparisons, pooled estimates and primary image-mean estimates.
- training_history.csv and validation_p0_history.csv: all five epochs for all three groups.
- local_scale_p2.csv and condition_highlights.csv: stride, crop/view, depth/edge, overlap, and seam summaries.
- example_images.csv: representative extreme per-image changes selected by the analysis script.
- checkpoint_sha256.txt: common initialization and final epoch-5 checkpoint hashes.
- figures/: three SVG result plots; generated by plot_results.py using the Python standard library only.

The control group's absolute RMSE does not reproduce the prior epoch-20 E0/B0 reference. This is called out in report_ja.md and remains an unresolved result limitation.
