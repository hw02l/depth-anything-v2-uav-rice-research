# 実験計画：深度誤差要因の総合分析

## 目的

保存済みのB0–B3、E0–E3、C0/F1/F2 × P0/P1/P2のValidation128評価を再集計し、絶対深度RMSEの悪化と局所深度差の過小推定に関係する要因を定量化する。新たな学習は行わない。

## 固定条件

- 検証標本はValidation128のみとし、GTマスクは有限値かつ `0 < Z <= 65 m` とする。
- 局所差は元画像上の14/28/56/107/214px距離とし、全有効ペアと `|ΔGT| >= 0.20 m` を分ける。
- 2026年11月15日確定のRGB入力修正版を正本とする。2026年11月14日の不具合評価値は使わない。
- Bootstrapは画像ID単位の対応付き再標本化、10,000回、seed 42とする。
- pooled値と画像単純平均を分ける。GTに対するoracle補正は診断値としてのみ扱う。
- 学習重み、optimizer、schedulerは変更しない。Independent test319は使わない。

## 分析項目

1. 9条件の絶対誤差、Bias・残差分散、Pred対GTの傾き・切片・Pearsonを再計算する。
2. 画像単位のRMSE・Bias・回帰統計と、距離別の局所MAE・RMSE・振幅比・符号一致率を集計する。
3. C0-P0、F1-P1、F2-P2を中心に、入力上の14px局所差の尺度、撮影方向、作物、GT深度・GT差、画像端、タイル境界で層別する。
4. B系列とE系列の保存済み結果を別表にし、9条件と混同せず原因候補を比較する。
5. 同一画像IDのpaired bootstrapで事前に設定された主要比較を再検証する。
6. 図表、テスト、入力ハッシュ、ソースリビジョン、実行環境、実行コマンドを保存する。

## GPU判断

既存の十分統計から実施できる分析を先行する。今回のGPGPU4確認ではGPU使用率は低い一方、他者のPythonプロセスが約2GBのVRAMを使用していたため、共有資源を使う新規推論は開始しない。C/Fの新しい予測マップが保存されていない点は未実施項目として記録する。
